RDAP Lookup

Registration Data Access Protocol (RDAP) — whois, modern. Pure client-side; queries the authoritative RDAP server via the IANA bootstrap.

RDAP server:
Bootstrap ON: queries the IANA-registered server for the queried TLD/network/ASN (per RFC 7484). Bootstrap OFF: queries the server above (default http://localhost:8443).
Enter a domain, nameserver, entity handle, IP/CIDR, or ASN to look it up.

ICANN Conformance (rdapct subset)

Client-side re-implementation of the most common ICANN RDAP conformance checks (STD 95 + 2024 Response Profile). Runs against the server URL above.
Select checks and press “Run selected checks”.

Built on RFC 9082/9083 (STD 95) and RFC 7484 (bootstrap). Icon-free, dependency-free, no data leaves your browser except the RDAP queries themselves.

Powered by go-rdap-server — a production-ready, ICANN-conformance-verified RDAP server written in Go.
